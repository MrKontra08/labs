Лабораторна робота №5

Варіант №2. Відтворення елемента header#logos_container з головної сторінки lpnu.ua.

Аналіз блоку

Три зображення-посилання на підрозділи та проєкти університету. Для компонування застосовано три рівні колонки, кожна займає одну третину контейнера. CSS демонструє властивості width, padding, margin, border, font-family та color.

HTML-структура та адреси зображень узяті з наданого вихідного коду lpnu.ua. Значення CSS — навчальне наближення, оскільки оригінальні computed styles у DevTools не надано.
